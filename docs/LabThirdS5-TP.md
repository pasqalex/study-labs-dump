# Локальные сплайны

Приближение функций локальными сплайнами на неравномерной сетке с адаптивным выбором порядка на каждом подотрезке.

## Что умеет

- Парсер математических выражений с функциями и константами
- Построение локального сплайна на произвольной сетке
- Использование узлов Чебышёва–Лобатто на каждом подотрезке
- Барцентрическая интерполяция для устойчивого вычисления
- Оценка погрешности на каждом подотрезке (max, rms)
- Контроль устойчивости через разброс весов (w/w)
- Сравнение с глобальным полиномом той же степени
- Обработка открытых и закрытых границ отрезка
- Поддержка особых точек (NaN, бесконечности) — они пропускаются

## Запуск

dotnet run

## Ввод

Программа спрашивает по шагам:

- f(x) — выражение, например 1/cos(x) или x^(1/x)
- a, b — границы отрезка (можно вводить выражения: pi/2, pi)
- тип границ: 1 — закрытая, 2 — открытая
- eps — отступ от открытой границы
- m — базовый порядок сплайна на подотрезке
- m_spec — порядок на граничных подотрезках (если границы открыты)
- control points — число контрольных точек для оценки погрешности

## Структура

Весь код в одном файле Program.cs.

- ExpressionParser — разбор выражений. Поддерживает + - * / ^, скобки, sin cos tan exp ln log10 sqrt abs pow, константы pi, e, переменную x.
- BarycentricInterpolant — интерполянт в барицентрической форме. Устойчив, не страдает от эффекта Рунге.
- LocalSpline — сам сплайн. Хранит сетку, порядки, куски. Умеет оценивать значение и погрешность.
- Program — ввод, построение, вывод таблиц.

## Теория

На каждом подотрезке [x_i, x_{i+1}] строится интерполянт по узлам Чебышёва–Лобатто:

ξ_k = cos(kπ/m), k = 0..m

Узлы отображаются на подотрезок линейной заменой. Интерполяция — барицентрическая:

P(x) = Σ (w_j / (x - x_j)) * y_j / Σ (w_j / (x - x_j))

где веса w_j = 1 / Π_{k≠j} (x_j - x_k).

Устойчивость контролируется отношением max|w| / min|w|. Чем оно ближе к 1, тем лучше обусловлена интерполяция.

Оценка погрешности — по контрольным точкам внутри подотрезка. Считаются max и rms отклонения от точного значения функции.

## Вывод

Три таблицы:

1. По подотрезкам: диапазон, порядок, max-ошибка, rms-ошибка, разброс весов.
2. Глобальная оценка: максимальная ошибка сплайна и глобального полинома.
3. Детальная таблица: значения f(x), S(x), P(x) и ошибки в контрольных точках.

## Пример

f(x) = 1/cos(x)
a = pi/2, тип: открытая
b = pi, тип: закрытая
eps = 1e-4
m = 4
m_spec = 8
control points = 10

На выходе — таблица по подотрезкам с оценкой погрешности и сравнение с глобальным полиномом.
