<h1>Разложение функций в ряд Фурье по ортогональным многочленам.</h1>

## Что умеет

- Парсер математических выражений с функциями
- Приведение отрезка [a, b] к [-1, 1] линейной заменой переменной
- Разложение функции по трём системам ортогональных многочленов:
  - многочлены Чебышева I рода (вес `1/sqrt(1-x^2)`)
  - многочлены Чебышева II рода (вес `sqrt(1-x^2)`)
  - многочлены Лежандра (вес `1`, рекуррентная формула)
- Вычисление коэффициентов Фурье составной квадратурой Симпсона
- Оценка погрешности приближения в метрике `L^2[a, b]`
- Сравнение точности трёх систем при заданном порядке `n`
- Построение таблицы значений `f(x)` и частных сумм `S_n(x)` на сетке
- Обработка особых точек (деление на ноль, бесконечности, NaN)

## Запуск

dotnet run

## Режимы

y - построить таблицу значений на равномерной сетке
n - только коэффициенты и погрешности

## Пример

f(x) = x^(1/x)

Отрезок: [0, 1]

Порядок частной суммы n: 20

## Структура

Program.cs - весь код в одном файле

Parser    - разбор выражений, умеет sin cos tan exp ln log10 sqrt abs pow

Chebyshev - многочлены Чебышева I и II рода, коэффициенты Фурье, L2-оценка

Legendre  - рекуррентное вычисление многочленов Лежандра, коэффициенты, L2-оценка

Quadrature - составная квадратура Симпсона

Table      - вывод таблицы f(x), S_Cheb1, S_Cheb2, S_Legendre

## Теория

Ортонормированные системы на [-1, 1]:

- Чебышев I:  T_n(x) = cos(n arccos x),         h(x) = 1/sqrt(1-x^2)
- Чебышев II: U_n(x) = sin((n+1) arccos x)/s,   h(x) = sqrt(1-x^2)
- Лежандр:    P_n(x) = (1/(n! 2^n)) [(x^2-1)^n]^(n),  h(x) = 1

Коэффициенты Фурье:

a_n = ∫ f(t) * poly_n_hat(t) * h(t) dt

Ряд: f(x) ≈ Σ a_k * poly_k_hat(x)
