<h1>Аппроксимация функции многочленом методом наименьших квадратов.</h1>

## Что умеет

- Парсер математических выражений с функциями
- Построение многочлена заданной степени по точкам
- Нормализация отрезка на [-1, 1]
- Решение СЛАУ методом Гаусса с выбором главного элемента
- Обработка особых точек (деление на ноль, бесконечности)
- Открытые и закрытые границы отрезка

## Запуск

dotnet run

## Режимы

y - ручной ввод

n - тест x/sin(x) на (pi, 3pi/2]

## Пример

f(x) = x/sin(x)

Отрезок: (pi, 3pi/2]

Число точек: 15

Степень: 4

## Структура

Program.cs - весь код в одном файле

Parser - разбор выражений, умеет sin cos tan cot exp ln log sqrt abs pow

Builder - строит многочлен, нормализует отрезок, решает СЛАУ

Approx - считает значение многочлена в точке
