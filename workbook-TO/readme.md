## Возможные проблемы

### Ошибка `BrowserError: Browser closed unexpectedly`

Это значит, что запущена **старая** ячейка с `pyppeteer`. Удали её.

Правильный код:
- **НЕ** содержит `pyppeteer`
- **НЕ** содержит `launch`
- **НЕ** содержит `await main()`
- Начинается с `from weasyprint import HTML`

## Как изменить содержимое

Весь текст страниц лежит в списке `pages` в `generate.py`. Каждый элемент - кортеж:

```python
(title, body_html, color_key)
```

Где:
- `title` - заголовок страницы (строка)
- `body_html` - HTML-содержимое без `<html>` и `<head>` (строка)
- `color_key` - `"green"` или `"blue"` (чередование для разворотов)

Чтобы добавить страницу - просто допиши новый `pages.append(...)`.

Чтобы изменить цвета - отредактируй словарь `COLORS`:

```python
COLORS = {
    "green": ("#e8f5e9", "#1b5e20"),  # (фон, акцент)
    "blue":  ("#e3f2fd", "#0d47a1"),
}
```
